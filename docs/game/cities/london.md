# Londýn / London

**Trasa** — Westminster → Victoria Tower Gardens → Westminster Bridge → South Bank → Bankside → City → Tower Bridge.
**Pohlednice** — scéna LON10.
**Ověřeno** — 26. 11. 2026. Záběr v návrhu se při výrobě srovná s označenou fotografií podle §9 zadání. Tučně je správná volba. Zobrazené pořadí určuje §3 zadání.

- **Po odpovědi CS** — Na Parliament Square je před tebou Elizabeth Tower, běžně nazývaná Big Ben podle zvonu uvnitř.
